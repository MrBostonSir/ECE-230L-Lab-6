## Lab Summary
We learned how to add two numbers together in binary using logic gates, as well as how to increase the number of bits we are able to add. To do this we created a second adder, then used the carry out of the previous adder in the circuit.

## Lab Questions
### 1 - How might you add more than two bits together?
You would just keep chaining full adders together, one for each bit in the largest number.

### 2 - What is the importance of the XOR gate in an adder?
The XOR gate is important because it is the gate that supplies the sum of the addition. 

### 3 - What is the largest number a two bit adder can handle? What happens when
you go over?
The largest number a 2 bit adder can handle is 3, which is denoted as 11. If you try to go over this, there will be an overflow, and if the system cannot handle this it will lose information.
